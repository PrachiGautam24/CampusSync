## 🗺️ Quick Navigation Guide

### From Dashboard:

**Find Rooms** → Search & book study rooms  
**Events** → Browse workshops & hackathons  
**Help Hub** → Ask for help or offer assistance  
**Lost & Found** → Report or find lost items

### Bottom Navigation:

**Home** → Return to Dashboard  
**Rooms** → Quick access to Room Finder  
**Activities** → Browse all campus activities  
**Profile** → Your profile & settings

### Header Icons:

**Bell** 🔔 → View notifications  
**Profile Picture** → Open profile settings

## ✨ Key Features to Test

### 1. Room Booking
- Dashboard → Find Rooms
- Select date, time, block
- Click Search
- Choose a room → Book Room
- Select purpose → Confirm
- Check "My Bookings" tab

### 2. Post a Help Task
- Dashboard → Help Hub
- Click "Post a Task"
- Fill form → Submit
- View in "All Tasks"

### 3. Report Lost Item
- Dashboard → Lost & Found
- Click "Report Item"
- Choose Lost or Found
- Fill details → Submit

### 4. Browse Events
- Dashboard → Events
- Search or filter by category
- Click event → View details
- Add to Calendar

### 5. Check Notifications
- Click bell icon (top right)
- View all notifications
- Click any to see details

## 🐛 If Something Doesn't Work

1. Check terminal for errors
2. Restart: `Ctrl+C` then `npm start`
3. Clear cache: `npx expo start -c`
4. Check you're on the web version
5. Try different browser
